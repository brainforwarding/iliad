# Iliad MD v0.7.0

Iliad MD v0.7.0 is a signed and notarized macOS release for Apple Silicon Macs.

## What's New

### Comments in the margin

Press ⌃⌘M, or the Comments button at the top right of the window, and every comment on the document is written out in the right margin beside its passage. You no longer have to hover passages one at a time to read them.

Point at a comment to see its passage and a small × that deletes it. Click a comment to open it with Edit and Delete. When a paragraph has many comments, long ones end in "…" and the rest fold into "+2 more"; click either to read them in full.

### Ask an agent for feedback without it editing your text

Claude Code, Codex and other agents can now leave comments of their own. Ask for feedback on a document and the agent adds comments to its comments file instead of changing the text. They show up in the margin marked ✦, next to your own comments. When the margin is hidden, they leave no mark in your text.

Run `iliad skill install` once so Claude Code learns how to leave comments; other agents can read the same guide with `iliad skill print`.

### Fixes

- When two comments sit close together, moving the pointer from the first one toward its card no longer switches to the second comment on the way.
