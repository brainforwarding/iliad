# Iliad MD v0.6.2

Iliad MD v0.6.2 is a signed and notarized macOS release for Apple Silicon Macs.

## What's New

### The Update button shows what the update is doing

While an update downloads, the button at the bottom of the sidebar draws a thin ring that fills as the download moves. Point at it to read the progress, for example "Downloading 42%".

When the update is ready, the button turns into a restart button. Point at it and it says "Restart to update", the same words you see in Settings. Click it and Iliad saves your work and restarts on the new version.
