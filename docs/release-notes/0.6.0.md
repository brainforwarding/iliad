# Iliad MD v0.6.0

Iliad MD v0.6.0 is a signed and notarized macOS release for Apple Silicon Macs. From this version on, Iliad updates itself.

## What's New

### Iliad updates itself

- Iliad checks for a new version when it opens and every few hours after that, and downloads it in the background.
- When it's ready, a small button appears at the bottom of the sidebar, next to Settings. Click Update and Iliad saves your work, closes and opens again on the new version.
- If you don't click, the update installs the next time you quit Iliad.
- If your agent has changes you haven't reviewed yet, Iliad asks before restarting. Those changes stay on disk as they are.
- Settings → General shows the same thing in words, with Check now.
- This is the last time you update by hand. Download 0.6.0 once and the next versions arrive on their own.

### A new icon

The paperclip is redrawn. It's the same idea with a cleaner, bolder line that reads well in the Dock and at small sizes.

### Support Iliad

Iliad is free and MIT licensed, and it will stay that way. If it earns a place in your writing, Settings → General has a Buy me a coffee link.

## Homebrew

The Homebrew cask now says Iliad updates itself, so `brew upgrade` leaves it alone and the app keeps itself current. `brew upgrade --greedy` still works if you prefer it.
