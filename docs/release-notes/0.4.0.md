# Iliad MD v0.4.0

Iliad MD v0.4.0 is a signed and notarized macOS release for Apple Silicon Macs. The built-in AI now works the first time you open Iliad, with no key and no account, and it only runs when you ask for it.

## What's New

### AI included, free, with a daily limit

Inline completion (`⌘,` `⌘.` `⌘/`) and the ✦ AI menu work right away. There is nothing to set up: no key, no account, no sign-in.

The free AI has a daily limit, shared by autocomplete and ✦ AI. Iliad never shows a counter. If you reach the limit, a short notice near the cursor says when it comes back (limits reset at 00:00 UTC, shown in your local time).

It runs on Groq, with the `openai/gpt-oss-120b` model. In free mode your request goes through Iliad's server, which passes it to Groq and keeps none of your text. Groq's Zero Data Retention is on for Iliad's account, so Groq doesn't keep it either. The [privacy page](https://iliad.md/privacy/) explains exactly what is sent and who sees what.

### Or use your own Groq key

In **Writing assists**, choose **Use my key** and paste a Groq API key (**Get a key** opens the Groq console). Iliad checks the key with Groq before saving it, and stores it encrypted on your Mac, protected by the macOS Keychain. With your own key, requests go straight from your Mac to Groq, with no Iliad server in between and no daily limit from Iliad; your Groq account's own limits and terms apply. Iliad never switches between the two routes on its own: if your key fails, Iliad tells you instead of falling back to the free route.

### Suggestions only when you ask

Iliad no longer suggests while you type. Suggestions come only from the length keys: `⌘,` a sentence, `⌘.` a paragraph, `⌘/` the full idea. Your text is sent only when you press one of them or pick a ✦ AI action. See [Autocomplete](https://iliad.md/learn/?doc=autocomplete).

`⌘↵` now does one thing: with text selected, it opens the ✦ AI menu. With nothing selected it does nothing.

### A simpler Writing assists menu

Every setting is one plain row: Corrector, Autocomplete, the keys (which you can change in place), the AI row (**AI included** or your Groq key), and **Privacy**, which opens the privacy page. Screen readers always announce a suggestion when it appears, so the separate setting is gone.

### Install and set up from the terminal

- `iliad install` puts the `iliad` command on your PATH straight from the app bundle (`"/Applications/Iliad MD.app/Contents/Resources/bin/iliad" install`), with no menu click, so an AI agent can set Iliad up for you. `iliad uninstall` removes only the links it created.
- Homebrew: `brew install --cask brainforwarding/tap/iliad-md` installs the app and the `iliad` command.
- Every release now has a stable download link: `https://github.com/brainforwarding/iliad/releases/latest/download/Iliad-MD-arm64.dmg`.
- New to Iliad and using Claude Code or Codex? Tell your agent: "Set up Iliad for me: follow https://iliad.md/install.md".

## What Was Removed, And Why

- **Gemini.** Setting up a Gemini key was the first thing a new writer ran into, and most people never did it. Groq now powers all built-in AI, free by default.
- **Automatic suggestions**, with **Suggest while I type** and **Pause for 10 min**. Suggestions that arrive uninvited pull you out of your own sentence, and any pause could send your text without you asking. Asking with a key keeps you in charge of both.
- **Writing notes** (`name.notes.md` and **Open notes**). Comments already are how you tell your agent what you want; notes duplicated them. Comments stay exactly as they were.

## How To Migrate

- **Nothing to set up for AI.** It works on first launch.
- **Saved Gemini keys are no longer used.** On first launch, Iliad deletes the saved Gemini key from your Mac. If you want no daily limit, add a Groq key under **Writing assists → Use my key**.
- **Existing notes files stay.** Iliad doesn't delete, rename, or move any `name.notes.md` file. It now shows up in the file tree as an ordinary document, and the Iliad skill treats it like any other document. Move anything you still need into the document or a comment.
- **Reinstall the skill** if you use Claude Code (`iliad skill install`) or refresh your `AGENTS.md` with `iliad skill print`, so your agent stops looking for notes.
