Iliad · Design Guidelines

Flow

A calm, content-first writing workspace on warm paper. Graphite carries interaction, gold is the one warm brand note, and the agent's edits arrive as soft markers under the words — never blocks of colour over them. Values are enforced in src/styles/tokens.css; this page is the visual reference.

Principles

  • Text is the focus; chrome recedes. Cream canvas, near-white panels, hairline separation. No grey mass that competes with the writing.
  • One colour, one meaning. Graphite = interactive · gold = brand + highlight · green = added · coral = removed · blue = comment · amber = pending. Two families never share a hue.
  • Restraint. System fonts, weights 400–700, two radii. Add a semantic token before any new value.
  • Personality through motion, not ornament. The mascot has no face; it's alive because it moves. The writing column never moves.
  • Best practices over invention. Adapt the converged pattern quietly; don't reinvent.

The bottom-half wash

Every persistent mark over readable text (diff, comment, highlight) is a fixed band low on the line — not a full-height block. Glyphs stay clean; a page of edits reads as calm annotation. Live text selection is the one exception (full height, so it dominates).

.mark {
  background-image: linear-gradient(var(--c), var(--c));
  background-size: 100% 0.62em;        /* fixed band — identical for every tier */
  background-position: 0 90%;           /* low on the line */
  background-repeat: no-repeat;
  box-decoration-break: clone;          /* hug text, stop at its end, wrap right */
}

Diff — two tiers, sentence-level

The agent's review shows whole sentences added/removed, with the words that actually changed in a stronger shade. Both tiers share the band; only the alpha differs.

Rules: compute a word-level intradiff (common prefix/suffix stay soft, only the differing run goes strong). Removed adds strikethrough. Collapse single-sided edits — a pure one-word insertion/deletion shows on one line, not two near-identical washed sentences. Impl: src/editor/aiReview/diff.ts + extension.ts.

Mascot — the clip

A faceless gold paperclip — no eyes (an eyed clip in an AI writing app reads as Clippy). Personality comes from motion: it sways/breathes, hops on click or idle, and droops to sleep on a crash. Click it. Component: src/components/ClipMark.tsx.

Typography

System stacks are the brand — no web fonts (offline, fast, native).

Serif canvas — Iowan Old Style --font-serif · prose & headings
Sans chrome — Avenir Next / system-ui --font-sans · UI
Mono — ui-monospace / Menlo --font-mono
Weights: 400 · 500 · 600 (emphasis) · 700 (avoid in chrome)

Motion is ambient and quiet: active-file light sheen ~7–10% over ~13s; agent presence = a slow breathing dot (pulses gold). Glass (backdrop-filter) only on floating surfaces (typography popover, launch/overlay) — never the file rail or editor. The writing column never animates.
