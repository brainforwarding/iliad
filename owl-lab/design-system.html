Iliad MD

A local-first Markdown writing workspace. The design system below mirrors the real tokens in src/styles/base.css (source of truth there).

Principles

  • Paper, not screen. Warm off-white grounds, never clinical white.
  • One accent. A single muted teal carries every interactive signal.
  • Restraint. Fewer things, better spaced. Hairlines and whitespace over boxes.
  • Source is the contract. The on-disk Markdown is truth; the UI never mutates it silently.
  • Serif writes, sans operates. Serif for prose, sans for chrome — quiet hierarchy.
  • One source of truth. Every colour, font, size and shadow is a semantic token in src/styles/tokens.css — ~26 colours, 6 sizes, 4 weights. Raw hex/rgba anywhere else is a lint error (npm run lint:css). This doc links that file, so it cannot drift.

Motion

The owl mostly sits, blinks to a little smile on a long loop, and gives a rare hop + wing-flash. Tooltips fade ~120ms; overlays slide-in ~160ms; the empty state rises ~360ms. All motion is disabled under prefers-reduced-motion.

Two parts work together while the agent runs: the existing thinking dots (the 3-dot wave shown in the transcript), plus a whisper-quiet inner green glow that breathes from the edges inward — ambient presence, not a spinner. Both fade out and stop under reduced-motion.

Guidelines

Voice & accessibility

Voice

  • Calm, plain, and concrete. Sentence case for everything except small uppercase section labels.
  • Fully bilingual (en / es) — every string lives in src/i18n/strings.ts.
  • Say what happened plainly; never blame the user.

Accessibility

  • One visible focus ring everywhere: 0 0 0 2px rgba(25,111,100,.14) + border #9db4ad. Tooltips are not focus indicators.
  • Body text ≥ 4.5:1; small meta ≥ 4.3:1 (#62675f).
  • Hit targets ≥ 30px. All motion respects prefers-reduced-motion.

Guidelines

Do / Don't

Do

  • Use the owl only in empty, idle, and brand moments.
  • Separate with space and hairlines.
  • Keep one accent; let teal mean "interactive".
  • Reach for the two radii and the meta-label pattern.

Don't

  • Put illustration or chrome on the writing canvas.
  • Watermark or rewrite the user's Markdown.
  • Introduce a second accent color or heavy bold.
  • Outline everything — boxes-in-boxes.
